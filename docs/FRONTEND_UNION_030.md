# 前端默认并集 · 0.3.0

负责人明确要求前端默认采用已选定的组合方案。上传后自动执行：
纯视觉加速v2（960全图刷新/256人物裁图，5fps）→全图及左右下部70%
区域剪辑检测（4fps/320宽/原阈值）→恢复超60秒活动并取边界并集→导出。
无需用户选择模式。权重未改，不使用音频判断；视频可能保留原声。

模型推理保留GPU优先/CPU失败回退机制，剪辑检测和媒体导出使用CPU。
本次真实视频验收在CPU执行；未把过去完整版的GPU性能当成此次加速并集性能。
单元测试仍覆盖GPU会话回退机制。
